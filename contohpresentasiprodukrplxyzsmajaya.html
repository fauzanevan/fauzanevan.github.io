SLIDE 02

Latar Belakang

  • Kesulitan Mengatur Deadline
    Banyak siswa kesulitan mengatur deadline tugas dari berbagai mata pelajaran.
  • Tidak Ada Pengingat Otomatis
    Tidak ada sistem pengingat otomatis untuk jadwal pengumpulan tugas.
  • Sulit Memonitor Progres
    Guru sulit memonitor progres pengerjaan tugas siswa secara real-time.
  • Butuh Solusi Praktis
    Dibutuhkan aplikasi yang praktis dan mudah digunakan untuk semua pihak.
SLIDE 03

Tujuan Pengembangan

  • Mengelola Daftar Tugas
    Memudahkan siswa mengelola dan mengorganisir daftar tugas dari semua mata pelajaran.
  • Pengingat Otomatis
    Memberikan notifikasi pengingat deadline otomatis agar tidak ada tugas terlewat.
  • Dashboard Progres
    Menampilkan dashboard visual untuk memonitor progres pengerjaan tugas.
  • Komunikasi Efektif
    Membangun jembatan komunikasi yang lebih baik antara siswa dan guru.
SLIDE 04

Fitur Utama TaskMaster

Tambah & Edit Tugas
Tambahkan tugas baru dengan mudah dan edit informasi kapan saja. Lengkapi dengan mata pelajaran, deadline, dan prioritas.
Reminder Otomatis
Dapatkan notifikasi pengingat otomatis sebelum deadline. Atur preferensi waktu pengingat sesuai kebutuhan.
Dashboard Progress
Visualisasi progres tugas dengan grafik dan statistik. Monitor tugas selesai, pending, dan overdue dalam satu tampilan.
Mode Guru
Guru dapat mengirim tugas, set deadline, dan memonitor progress siswa secara real-time dengan laporan lengkap.
SLIDE 05

Teknologi yang Digunakan

Frontend: React JS
Library JavaScript untuk membangun user interface yang interaktif dan responsif
Backend: Node.js + Express
Runtime JavaScript dan framework untuk membangun REST API yang scalable
Database: Firebase / MySQL
Sistem database cloud untuk menyimpan data tugas dan user secara aman
UI Toolkit: TailwindCSS
Framework CSS utility-first untuk styling yang cepat dan konsisten
Version Control: GitHub
Platform untuk version control dan kolaborasi tim development
