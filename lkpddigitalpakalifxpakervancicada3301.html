Latar Belakang & Tujuan

Mengapa kita membuat proyek ini?

Latar Belakang

Di era digital, pemahaman logika pemrograman sangat vital. Proyek ini mensimulasikan sistem kasir minimarket untuk melatih pemahaman alur transaksi, perhitungan total belanja, dan penerapan struktur data dasar dalam kasus nyata.

Tujuan Pembelajaran

  • Konsep Dasar Menerapkan Variabel, Array, dan Perulangan (Looping).
  • Algoritma Membuat algoritma perhitungan total belanja & diskon otomatis.
  • Kreativitas Mengembangkan fitur tambahan seperti PPN, Login Admin, atau Cetak Struk.

Logika Program & Struktur Data

Bagaimana program ini bekerja di balik layar?

Variabel Utama yang Dibutuhkan

string namaBarang[] int harga[] int jumlah[] long total

1. Input Data

User memasukkan nama, harga, dan jumlah barang. Gunakan For Loop jika barang lebih dari satu.

1
2

2. Proses Hitung

Subtotal = Harga * Jumlah
Akumulasikan ke variabel Total.

3. Cek Diskon (Logika IF)

Jika Total > 100.000, berikan diskon 10%. Hitung Grand Total setelah dipotong diskon.

3
4

4. Output Struk

Tampilkan daftar belanjaan dengan rapi menggunakan cout dan manipulasi spasi/tab.
